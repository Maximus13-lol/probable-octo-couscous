# Политика конфиденциальности / Privacy Policy — Shorts bot

_Дата обновления / Last updated: 11.11.2026_

## Русский

**Shorts bot** — личный инструмент владельца этого репозитория для автоматической публикации
собственных коротких видео на его YouTube-канале. Приложение не предназначено для других пользователей.

- **Какие данные используются.** Приложение получает доступ к YouTube-аккаунту владельца через OAuth
  (разрешения `youtube.upload` и `youtube.readonly`) только для загрузки собственных видео владельца
  и чтения публичной статистики видео при поиске трендов.
- **Хранение.** Токен доступа хранится только в зашифрованных секретах GitHub Actions этого репозитория.
  Приложение не собирает, не хранит и не передаёт третьим лицам персональные данные пользователей YouTube.
- **Передача третьим лицам.** Данные YouTube-аккаунта никому не передаются и не продаются.
- **Отзыв доступа.** Доступ можно отозвать в любой момент на странице
  <https://myaccount.google.com/permissions>.
- **Сервисы Google.** Использование данных соответствует
  [Политике конфиденциальности Google](https://policies.google.com/privacy) и
  [Условиям использования YouTube](https://www.youtube.com/t/terms).
- **Контакты.** Вопросы — через раздел Issues этого репозитория.

## English

**Shorts bot** is a personal tool of this repository's owner that automatically publishes the owner's own
short videos to the owner's YouTube channel. It is not intended for other users.

- **Data used.** The app accesses the owner's YouTube account via OAuth (`youtube.upload`, `youtube.readonly`)
  solely to upload the owner's own videos and to read public video statistics for trend research.
- **Storage.** The access token is stored only in this repository's encrypted GitHub Actions secrets.
  The app does not collect, store, or share personal data of YouTube users.
- **Sharing.** YouTube account data is never shared with or sold to third parties.
- **Revoking access.** Access can be revoked at any time at <https://myaccount.google.com/permissions>.
- **Google services.** Data use complies with the [Google Privacy Policy](https://policies.google.com/privacy)
  and the [YouTube Terms of Service](https://www.youtube.com/t/terms).
- **Contact.** Please use this repository's Issues section.
