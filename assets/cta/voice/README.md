# Живая озвучка концовки

Положите сюда 3–5 своих записей просьбы подписаться (mp3, m4a, wav, ogg/opus — подойдёт запись с телефона
или голосовое из мессенджера). Длительность 2–6 секунд, каждая запись — отдельный файл.

Конвейер в каждом ролике берёт случайную запись (не ту же, что в прошлом ролике), обрезает тишину по краям
и выравнивает громкость под озвучку истории. Если папка пуста — концовку озвучивает Vosk, как раньше.

Примеры текста:
- «Понравилась история? Подписывайся — завтра будет новая тайна!»
- «Если любишь загадки — жми подписку, впереди ещё много интересного.»
- «Подписывайся на канал, чтобы не пропустить следующую историю!»
- «Ставь лайк и подписывайся — разгадаем вместе ещё не одну тайну.»
- «Хочешь ещё таких историй? Подписка — и до встречи в следующем ролике!»
