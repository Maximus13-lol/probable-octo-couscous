# Длинные выпуски «Папки №13»

Workflow **Daily long video** готовит выпуск на 14:30 по Москве. Запуски GitHub Actions выбирают свободную дату заранее, вплоть до предыдущего дня. Тема, сценарий и материалы подбираются автоматически. Сценарий основан на статье Википедии, а кадры берутся из Wikimedia Commons с указанием авторства, лицензии и ссылки. Сборка проверяет структуру сценария, отсутствие дословных повторов и длительность 10–30 минут.

Короткая заставка идёт без озвучки. За ней сразу начинается рассказ. Если название канала встречается в тексте, оно передаётся озвучке одной фразой «Папка номер тринадцать».

YouTube получает время отложенного выхода, а Actions сохраняет ID ролика и результат обработки в `long/delivery/ГГГГ-ММ-ДД.json`. Если запрос на загрузку оборвался и ID получить не удалось, запись `pending` предохраняет от повторной публикации за эту дату. Следующие даты продолжают обрабатываться.

Используются существующие секреты голоса автора, Gemini или OpenRouter и YouTube OAuth. Для паузы можно установить переменную Actions `LONG_PUBLICATION_ENABLED=false`.

Workflow **Long video pilot (no upload)** позволяет проверить монтаж без загрузки. Для него можно передать JSON-досье с заголовком, коротким текстом обложки и главами. Каждая глава содержит текст, путь к кадру, автора, лицензию и HTTPS-ссылку на источник.
