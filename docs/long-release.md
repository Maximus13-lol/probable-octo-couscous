# Длинные выпуски «Папки №13»

## Тестовый выпуск

Workflow **Long video pilot (no upload)** сохраняет видео, обложку и источники в артефактах GitHub Actions. Поле `dossier` принимает путь к JSON-досье. Пустое поле запускает короткий тест с синтетическим звуком. Для полного пилота в PR используется досье о краже Моны Лизы и текущая конфигурация голоса автора.

Досье содержит `title`, короткий `headline`, необязательный словарь `references` и массив `chapters`. Для каждой сцены нужны `text`, путь к `image` внутри каталога досье, `credit`, `license` и HTTPS `source_url`. Для превью можно указать `preview_image` с главным портретом или предметом. Первый кадр выступает фоном. Для заголовка используется встроенный кириллический Fira Sans Condensed ExtraBold.

Проверьте формулировки сценария, права на материалы и готовый монтаж перед постановкой в очередь.

## Предпросмотр расписания

```bash
python -m src.long_schedule 2026-12-01 --count 14
```

Дата в команде приведена для примера. По умолчанию первая неделя ежедневная, далее между выпусками ровно два дня. Выходы распределяются между 15:10 и 16:40 по Москве с шагом в пять минут. Соседние выпуски не получают одинаковое время. Якорную дату и порядок уже поставленных в очередь досье сохраняйте. Новые досье добавляйте в конец списка.

## Отложенная публикация

Workflow **Long video release queue** запускается по расписанию. Выпуски выбираются из утверждённой очереди.

1. Добавьте `long/queue.json` с датой первого выпуска `start` в ISO-формате и массивом `dossiers` с путями от каталога `long/`. Для первой недели подготовьте минимум семь утверждённых досье и поставьте дату достаточно далеко, чтобы успели собраться вступительные выпуски.
2. Убедитесь, что Actions может записывать служебный журнал `long/delivery/` в основную ветку и что уже настроены секреты голоса автора и OAuth YouTube.
3. Для временной паузы установите `LONG_PUBLICATION_ENABLED=false`. При каждом запуске выбирается ближайший свободный выпуск в пределах восьми дней. Готовый ролик загружается с датой отложенного выхода. Для каждого выпуска сборка создаёт JPEG-превью и передаёт его в YouTube. Результат установки сохраняется в поле `thumbnail` записи о выпуске. Если до выпуска осталось менее 30 минут, загрузка блокируется.
4. Проверьте журнал Actions и запланированное видео в YouTube Studio. Запись `pending` означает, что попытка загрузки началась и её исход нужно сверить с каналом. Автоматический повтор в таком случае отключён, чтобы не получить дубль. Сохраняйте итоговый ID из артефакта или из YouTube Studio.

Для Shorts каждый второй первый вечерний слот сначала проверяет недавние публикации по теме загадок, архивов и открытий. Возраст измеряется по времени публикации новости. При выборе Gemini оценивает, есть ли в заголовке новое событие, а не пересказ старой истории. Если подходящего кандидата нет, основная подборка продолжает работу. Результат попытки записывается в `trends_report.json`.


## Вступление и монтаж

Каждый выпуск начинается с анимированной заставки «Папка №13» (2,6 секунды), затем авторский голос приветствует зрителя и анонсирует выпуск. Поле `opening` позволяет задать конкретный текст анонса.

Для автоматического выпуска досье должно содержать минимум 15 разных архивных кадров с источником, авторством и лицензией. Первый кадр главы задаётся прежними полями `image`, `credit`, `license`, `source_url`. Дополнительные кадры указываются в массиве `visuals` в порядке показа. Элемент с полем `prompt` создаёт иллюстрацию через тот же Pollinations, который используется для Shorts. Если в главе нет такого элемента, конвейер формирует запрос по её тексту. Реконструкции подписываются при монтаже. Для Pollinations используется существующий секрет `POLLINATIONS_TOKEN`, если он задан.

Кадры распределяются по коротким фрагментам речи. Фотография и размытый фон движутся в разных направлениях. Этот эффект добавляется при монтаже без звука переключения.
