# ad-inserter (`src/ads.py`, конфиг `ads/config.json`, лог `ads/log.json`)

## Когда пользователь присылает баннер в чат
1. Сохрани файл баннера в `ads/` (PNG с прозрачностью или JPG).
2. Уточни (если не сказано): рекламодатель, ссылка, даты начала/конца, позиция (`auto` по умолчанию), время показа (по умолчанию 40% ролика), длительность (4–6 с), для РФ — юр. лицо/ИНН и erid (маркировка ОРД).
3. Добавь кампанию:
   ```bash
   python -m src.ads add --banner ads/<файл>.png --advertiser "Имя" --url https://... \
       --start 2026-11-10 --end 2026-12-10 [--position auto|top-left|top-center|top-right|X,Y] \
       [--show-at 20] [--duration 5] [--legal "ООО ..., ИНН ..."] [--erid ...]
   ```
4. Сделай тестовый рендер и покажи пользователю превью-кадр и текст для описания:
   ```bash
   python -m src.ads test --campaign <id>       # на последнем output/*/video.mp4
   ```
   Результат: `output/ad_test_*/video_ad.mp4` и `ad_preview.jpg`.
5. Реклама применяется в ежедневных роликах только когда `"enabled": true` (`python -m src.ads enable`). Не включай без явного согласия пользователя.

## Правила размещения (зашиты в код)
- Только верхняя безопасная зона: y ∈ [210, 900], x ∈ [48, 1032] — под шапкой Shorts, выше субтитров (`SUB_ZONE` 1060–1420), не задевая колонку кнопок справа и нижнюю подпись. Ручные координаты тоже зажимаются в эту зону.
- `position: auto` → `find_empty_area()` берёт 5 кадров из окна показа, считает карту деталей (градиенты + контраст) и выбирает место с минимумом деталей.
- Непрозрачность 90% (`opacity`), плавное появление/исчезновение (`fade` 0.5 с), показ 4–6 с, никогда не раньше 3.5 с (хук не трогаем).
- На баннер добавляется плашка «Реклама» (`label` в конфиге).

## Выбор кампании
Активные = `enabled` + сегодня в [start_date, end_date] + файл существует. Истёкшие пропускаются с записью в лог. Из активных — та, у которой меньше всего показов (ротация). Одна реклама на ролик.

## Публикация и отчётность
- В описание добавляется «Реклама. Рекламодатель: … erid: …» и ссылка; в API ставится `paidProductPlacementDetails.hasPaidProductPlacement=true`.
- После успешной загрузки — запись в `ads/log.json` (дата, кампания, рекламодатель, видео, URL, время показа). Тестовые рендеры не логируются.
- Отчёт: `python -m src.ads report [--campaign <id>]`; список: `python -m src.ads list`.
- `python -m src.main --test-ad` — полный прогон с принудительной тестовой рекламой (без загрузки).
