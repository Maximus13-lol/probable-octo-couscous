# storyboard (`src/storyboard.py`)

Выход: `output/<run>/storyboard.json`:
```json
{"characters": [{"name": "keeper", "description": "bearded Scottish keeper, 40s, oilskin coat"}],
 "scenes": [{"index": 0, "text": "<дословный фрагмент истории>", "prompt": "<english image prompt>", "full_prompt": "..."}]}
```

## Проверки ответа Gemini
- 8–12 сцен; у каждой есть `text` и `prompt`; в `prompt` нет кириллицы.
- Склейка всех `text` (без пробелов и пунктуации) **дословно** равна истории — иначе тайминги озвучки разойдутся с текстом.
- Первая сцена — только хук.
- Персонажи описываются один раз в `characters`, а в промптах упоминаются по `name` — `style.build_prompt` подставит их описание (так они выглядят одинаково во всех сценах).

## Запасной режим
Если Gemini недоступен — `_fallback()` режет историю по предложениям на 8–12 сцен с общими промптами по `topic_en`.
