# story-writer (`src/story.py`)

Вход: выбранная тема (`choice` из trend-scout). Выход: `output/<run>/story.json`
(`title`, `hook`, `story`, `description`, `hashtags`, `word_count`).

## Правила текста (проверяются в `_validate`, при нарушении Gemini получает замечание и переписывает, до 4 попыток)
- 130–160 слов (`count_words`) — при `TTS_RATE=+12%` это ~55–65 с озвучки.
- Первое предложение — хук-вопрос, заканчивается на `?`, не длиннее 16 слов (звучит за первые ~3 с).
- В конце — развязка (ответ или самая правдоподобная версия) и цепляющая финальная фраза.
- Только факты/общепринятые версии, без жестокости; годы цифрами, остальные числа словами; без эмодзи.

## used_topics.json
`mark_topic_used()` дописывает `{topic, topic_en, source_title, title, date}`. При `--no-upload` тема не записывается (чтобы тесты не «съедали» темы), если не передан `--mark-used`. В Actions файл коммитится обратно в репозиторий после успешной публикации.

## Без ключа
Если `GEMINI_API_KEY` не задан — используется демо-история из `src/demo.py` (для локальной проверки конвейера).
